Основа: учебный проект b9, Tema_3.pdf, стр. 26–27.

В otdeli.c реализованы:
- Сохранение измененной строки через параметризованный UPDATE;
- Добавление записи с автоматическим ключом через INSERT;
- Удаление выбранной записи через DELETE.
Для сохранности связей нельзя удалить отдел, если к нему привязаны сотрудники.
Файл main.glade содержит назначенные сигналы кнопок Добавить/Удалить.
Ключ отдела не должен редактироваться вручную.
Все операции сразу выполняются в SQLite и обновляют GtkListStore.

ПРОВЕРКА (Windows):
1. Скопируйте b9 из Tema3_b2_configured/b9 в C:\Work\Tema3\b9.
2. Откройте C:\Work\Tema3\b9\bin\Debug\main.glade в Glade.
3. Проверьте window3 → treeview2 и кнопки Добавить / Удалить.
4. Откройте b9.cbp в Code::Blocks, нажмите F9.
5. Нажмите Отделы. Дважды щелкните значение Отдел/Руководитель,
   измените и нажмите Enter. Изменение сохраняется автоматически.
6. Нажмите Добавить: появится «Новый отдел». Отредактируйте его.
7. Выделите этот новый отдел и нажмите Удалить.
8. Откройте b9.db в SQLiteStudio → Отделы → Data → F5;
   убедитесь, что изменения соответствуют последнему состоянию.
9. Сделайте снимки: Glade, otdeli.c, программа после изменений
   и SQLiteStudio. Для демонстрации удаления перед удалением
   можно сделать отдельный снимок добавленной записи.

ВНИМАНИЕ: Используется копия учебной b9.db из GitHub. Рекомендуется
сохранить резервную копию перед опытом. Сборка/запуск на Windows
пока не подтверждены. Отчет пока черновой, без реальных снимков.
