## 1. Задание

## 2. Ход работы
На основе проекта b9 реализованы обработчики GtkTreeView/GtkButton, обращающиеся к SQLite через подготовленные запросы:
```sql
UPDATE Отделы SET Отдел=?, Руководитель=? WHERE [Код отдела]=?;
INSERT INTO Отделы(Отдел, Руководитель) VALUES(?, ?);
DELETE FROM Отделы WHERE [Код отдела]=?;
```
После успешного выполнения SQL обновляется модель GtkListStore. При удалении предусмотрена проверка ссылок из таблицы «Сотрудники», чтобы не нарушить связи данных. Изменение первичного ключа пользователем отключено.

## 3. Результат — ожидает проверки
