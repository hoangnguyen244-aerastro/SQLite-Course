# ОТЧЁТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ — ЧЕРНОВИК
**Тема 6 — Развёртывание SQLite (демонстрационный стенд на базе Фотосервиса)**

## Цель
Показать развёртывание готовой реляционной БД, контроль целостности, создание и восстановление резервных копий.

## Ход выполнения
Используются Python 3 и стандартный модуль sqlite3. Проверки: PRAGMA integrity_check, PRAGMA foreign_key_check, подсчет записей. Копирование: SQLite Online Backup API, без перезаписи целевого файла по умолчанию.
