ТЕМА 4 — ЗАДАНИЕ 5 — ПЕЧАТЬ ДАННЫХ ТАБЛИЦЫ «ОТДЕЛЫ»

Основа: учебный пример b14, урок 4.6. Преподаватель пишет:
«Пример b14 — вывод на печать реализован для таблицы "Сотрудники".
Задание: Реализовать вывод на печать для таблицы "Отделы"».
Задание реализовано на основе проекта b13, с сохранением предыдущих функций.

НОВЫЕ ВОЗМОЖНОСТИ
1. В форме w_otdel кнопка «Печать карточки» — печать записи отдела из SQLite.
2. В окне списка отделов window3 кнопка «Печать списка» — печать всех отделов, один отдел на странице.
3. Используется GtkPrintOperation, обработчики begin-print и draw-page; вывод через Pango/Cairo.
4. Карточка включает название отдела, руководителя, дату основания и изображение (если исходный файл доступен).
5. Запись читается из SQLite. Несохраненные изменения в полях формы НЕ включаются в печатный документ. Сохраните их перед печатью.

ДЛЯ ПРОВЕРКИ WINDOWS
1. В GitHub Desktop переключитесь на review/remaining-coursework-2026-11-23 и выполните Pull.
2. Скопируйте b14 в C:\Work\Tema4_b5\b14; исходные файлы b13 не изменяйте.
3. Откройте b14.cbp в Code::Blocks. Build → Rebuild → F9.
4. Отделы → выбрать запись (например, Hoang) → Открыть → Печать карточки.
5. В диалоге печати выберите предварительный просмотр или принтер PDF, если он доступен.
6. Сделайте реальный снимок окна предпросмотра или полученного печатного документа.
7. Вернитесь к списку Отделы → Печать списка. Проверьте количество страниц и содержание.
8. Откройте b14.db в SQLiteStudio, выполните SELECT для подтверждения данных и сделайте снимок.
9. Откройте bin/Debug/main.glade в Glade, снимите кнопки печати в w_otdel и window3.

SQL ДЛЯ ПРОВЕРКИ
SELECT [Код отдела], Отдел, Руководитель, Фото, [Дата основания]
FROM Отделы ORDER BY [Код отдела];

ОГРАНИЧЕНИЯ
- Это первая реализация: сборка под Windows и фактическая работа диалога печати ещё НЕ проверены.
- b14.db — независимая копия учебной БД; данные/фотография из b13 могут отличаться.
- Для печати кириллицы используется Pango; установленные шрифты и драйвер принтера влияют на результат.
- Если файл фото недоступен, карточка печатается без изображения.
- Точный текст красных заданий в PDF Tema_4.pdf еще нужно сопоставить до сдачи.
