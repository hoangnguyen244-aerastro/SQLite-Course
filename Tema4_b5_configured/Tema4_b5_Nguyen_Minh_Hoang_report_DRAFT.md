# ОТЧЁТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ — ЧЕРНОВИК
**Тема 4. Задание 5. Вывод на печать для таблицы «Отделы».**

## Цель работы
Разработать печатное представление карточки отдела и списка отделов на основе GTK+, SQLite и Cairo/Pango.

## Изменения в программе
- В Glade добавлены кнопки «Печать карточки» и «Печать списка».
- Файл print_departments.c содержит GtkPrintOperation и обработчики begin-print/draw-page.
- Карточка читает название, руководителя, дату основания и путь фотографии из SQLite.
- Список состоит из отдельных страниц по количеству записей таблицы «Отделы».

## SQL
```sql
SELECT Отдел, Руководитель, Фото, [Дата основания]
FROM Отделы WHERE [Код отдела]=?;

SELECT Отдел, Руководитель, Фото, [Дата основания]
FROM Отделы ORDER BY [Код отдела] LIMIT 1 OFFSET ?;
```

**Ограничение условий тестирования.** В распоряжении студента нет физического принтера, поэтому выполнить пробную печать карточки отдела на бумаге и проверить качество бумажного отпечатка не представилось возможным. При этом работоспособность вызова функции печати подтверждена открытием системного диалогового окна Windows после нажатия кнопки «Печать карточки». Корректность сформированного печатного документа и печать списка отделов требуют отдельной проверки. Отсутствие принтера не означает ошибку программной реализации.
