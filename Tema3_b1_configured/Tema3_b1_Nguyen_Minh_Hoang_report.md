## 1. Задание

Открыть проект `b8.cbp`. В модуле `sotrudniki.c`, в функции `LoadDB()`, изменить запрос и вывод данных так, чтобы в таблице «Сотрудники» отображалось поле «Руководитель» из таблицы «Отделы». Добавить соответствующее поле модели и колонку в `main.glade`.

## 2. Реализация

Для получения данных используется соединение таблиц по коду отдела:

```sql
SELECT [Код сотрудника], с.Фамилия, с.Оклад,
       Отделы.Отдел, Отделы.Руководитель
FROM Сотрудники AS с
JOIN Отделы
  ON с.[Код отдела] = Отделы.[Код отдела];
```

В `sotrudniki.c` добавлено поле `C_BOSS` и чтение значения из результата SQL-запроса. В `main.glade` добавлено поле модели GtkListStore и колонка TreeView с заголовком «Руководитель».
