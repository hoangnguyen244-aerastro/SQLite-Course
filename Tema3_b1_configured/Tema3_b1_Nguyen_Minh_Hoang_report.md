## 1. Задание
Открыть проект `b8.cbp`. В файле `sotrudniki.c` в функции `LoadDB()` вывести поле «Руководитель» из таблицы «Отделы» вместе с данными сотрудника. Добавить соответствующее поле модели в `main.glade`. Сдать отчет с реальными скриншотами Glade, измененного кода и результата программы в Code::Blocks.

## 2. Ход выполнения
В запросе соединения двух таблиц добавлено поле `Отделы.Руководитель`:
```sql
SELECT [Код сотрудника], с.Фамилия, с.Оклад,
       Отделы.Отдел, Отделы.Руководитель
FROM Сотрудники AS с JOIN Отделы
ON с.[Код отдела] = Отделы.[Код отдела];
```
В `sotrudniki.c` добавлен `C_BOSS` и чтение через `sqlite3_column_text(stmt, C_BOSS)`. В `main.glade` добавлены пятое поле в `liststore1` и колонка `treeviewcolumn8` с заголовком «Руководитель».
