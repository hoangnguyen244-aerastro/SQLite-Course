## 1. Задание
Открыть проект `b4.cbp`, создать таблицу «Сотрудники» из пяти полей, обеспечить вставку записей с заполнением всех полей и вывод всех пяти полей с учетом индексации SQLite, начиная с 0. Запустить F9 и нажать «Information»; включить скриншоты результатов и измененного кода в отчет.

## 2. Ход выполнения
В `b4/main.c` созданы пять полей `N`, `Фамилия`, `Имя`, `Отдел`, `Оклад`. Программа выполняет `CREATE TABLE`, `INSERT`, `SELECT` и обращается к данным через `sqlite3_column_*` с индексами 0–4. Файл проекта `b4.cbp` запускается в каталоге студента `C:\Work\b5`.

```sql
CREATE TABLE Сотрудники (
  N INTEGER, Фамилия TEXT, Имя TEXT, Отдел TEXT, Оклад INTEGER
);
SELECT N, Фамилия, Имя, Отдел, Оклад FROM Сотрудники;
```
