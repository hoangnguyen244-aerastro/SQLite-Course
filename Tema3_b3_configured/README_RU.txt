ТРЕБОВАНИЕ
По Tema_3.pdf, стр. 31: в SQLiteStudio открыть b9.db, создать запрос
для подсчета сотрудников в каждом отделе с двумя полями — названием
отдела и количеством сотрудников, создать на основе запроса VIEW,
сделать снимки SQL-кода, представления и результатов и включить
основное задание и снимки в отчет.

РЕАЛИЗАЦИЯ
01_query_employee_counts.sql — SELECT с LEFT JOIN и GROUP BY.
02_create_view.sql — удаление предыдущей версии VIEW (если есть),
создание VIEW «Количество_сотрудников_по_отделам» и SELECT для проверки.

LEFT JOIN сохраняет в результате отделы без сотрудников; COUNT по
коду сотрудника возвращает для них 0. Группировка выполняется по коду
и названию отдела.

ФАКТИЧЕСКАЯ ПРОВЕРКА
По снимкам SQLiteStudio от 22.11.2026:
- запрос выполнен без ошибки;
- VIEW создано и отображается в дереве Views базы b9;
- SELECT из VIEW возвращает 4 строки;
- значения: пустое название — 1, Администрация — 2,
  Бухгалтерия — 3, Склад — 2 (всего 8 сотрудников).

ПРЕДУПРЕЖДЕНИЕ О ДАННЫХ
Пустое название отдела присутствует в исходных данных базы и не
является синтаксической ошибкой запроса. Файл b9.db в папке задания
не содержит сохраненного VIEW: это исходная база, совпадающая с
учебным экземпляром. При необходимости воспроизведения выполните
02_create_view.sql в рабочей копии базы. Для архивирования результата
можно дополнительно сохранить копию базы после создания VIEW.

ВОСПРОИЗВЕДЕНИЕ
1. Сделайте копию b9.db и откройте ее в SQLiteStudio.
2. Откройте SQL Editor, выполните 01_query_employee_counts.sql.
3. Выполните 02_create_view.sql в той же базе.
4. Обновите дерево объектов, раскройте Views и проверьте
   «Количество_сотрудников_по_отделам».
5. Выполните SELECT из VIEW и сравните результат с отчетом.
