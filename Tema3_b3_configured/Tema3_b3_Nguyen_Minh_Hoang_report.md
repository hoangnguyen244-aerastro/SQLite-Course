## 1. Задание

В SQLiteStudio открыть базу данных `b9.db`, составить SQL-запрос для подсчета количества сотрудников в каждом отделе с двумя полями — наименование отдела и количество сотрудников, создать из запроса представление и приложить снимки SQL-кода, VIEW и выводимых данных.

## 2. SQL-запрос

```sql
SELECT o.Отдел AS "Наименование отдела",
       COUNT(s.[Код сотрудника]) AS "Количество сотрудников"
FROM Отделы AS o
LEFT JOIN Сотрудники AS s
  ON s.[Код отдела] = o.[Код отдела]
GROUP BY o.[Код отдела], o.Отдел
ORDER BY o.[Код отдела];
```

LEFT JOIN включает все отделы, в том числе не имеющие сотрудников. COUNT по коду сотрудника позволяет получить ноль для отдела без связанных записей. Группировка по коду и названию отдела не объединяет разные отделы с одинаковыми названиями.

## 3. Представление

Создано представление `Количество_сотрудников_по_отделам` на основе указанного SELECT. После создания оно появилось в дереве базы данных SQLiteStudio в разделе Views.

Проверочный запрос:

```sql
SELECT *
FROM "Количество_сотрудников_по_отделам"
ORDER BY "Наименование отдела";
```
