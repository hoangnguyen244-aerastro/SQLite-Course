## 1. Задание
В SQLiteStudio открыть базу данных `b9.db`. Создать SQL-запрос для подсчета количества сотрудников в каждом отделе и вывести два поля — наименование отдела и количество сотрудников. Создать из этого запроса представление. Включить в отчет скриншоты SQL-запроса, определения представления и выводимых данных.

## 2. Реализация
Для сохранения всех отделов, включая не имеющие сотрудников, выбран `LEFT JOIN`. Количество сотрудников считается выражением `COUNT(s.[Код сотрудника])`, группировка выполняется по коду и названию отдела:

```sql
SELECT
    o.Отдел AS "Наименование отдела",
    COUNT(s.[Код сотрудника]) AS "Количество сотрудников"
FROM Отделы AS o
LEFT JOIN Сотрудники AS s
    ON s.[Код отдела] = o.[Код отдела]
GROUP BY o.[Код отдела], o.Отдел
ORDER BY o.[Код отдела];
```

На основе запроса создается представление `Количество_сотрудников_по_отделам`. Полный код находится в `02_create_view.sql`.
