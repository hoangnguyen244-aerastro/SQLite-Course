## 1. Задание
В SQLiteStudio открыть базу данных `b9.db`, составить SQL-запрос для подсчета количества сотрудников по отделам с полями «Наименование отдела» и «Количество сотрудников», а затем создать и проверить представление SQL VIEW.

## 2. SQL-запрос
```sql
SELECT o.Отдел AS "Наименование отдела",
       COUNT(s.[Код сотрудника]) AS "Количество сотрудников"
FROM Отделы AS o
LEFT JOIN Сотрудники AS s
  ON s.[Код отдела] = o.[Код отдела]
GROUP BY o.[Код отдела], o.Отдел
ORDER BY o.[Код отдела];
```

Команда выполнена в SQLiteStudio 3.1.1 без ошибок. LEFT JOIN учитывает все отделы, а GROUP BY обеспечивает группировку по идентификатору и названию отдела.

## 3. Представление
Выполнено `CREATE VIEW "Количество_сотрудников_по_отделам" AS SELECT ...`. Представление появилось в дереве базы данных `b9 → Views (1)` и было проверено командой:

```sql
SELECT *
FROM "Количество_сотрудников_по_отделам"
ORDER BY "Наименование отдела";
```
