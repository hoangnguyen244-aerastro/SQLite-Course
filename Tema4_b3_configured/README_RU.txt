СДЕЛАНО В ИСХОДНОМ КОДЕ
- Создан независимый проект b12.cbp с рабочей базой bin/Debug/b12.db.
- При запуске программа добавляет поле Фото TEXT в таблицу Отделы, если оно отсутствует.
- Форма w_otdel дополнена GtkImage и кнопками Выбрать фото/Удалить фото.
- Путь к выбранному файлу сохраняется в Отделы.Фото вместе с названием и руководителем.
- При открытии существующего отдела сохранённое изображение отображается, если файл существует.
- Работа предыдущих задач (форма отдела и список руководителей) сохранена.

ВНИМАНИЕ
Изображение не копируется в SQLite как двоичный BLOB: хранится строка пути, как в учебном b12.
Перемещение/удаление исходного изображения приведёт к отсутствию картинки в интерфейсе.
В редакторе Glade и на машине студента проект ещё НЕ тестировался.

ПРОВЕРКА НА WINDOWS
1. Выполните Git Pull выбранной ветки review/remaining-coursework-2026-11-23.
2. Скопируйте Tema4_b3_configured/b12 в C:\Work\Tema4_b3\b12.
3. Откройте b12.cbp в Code::Blocks; настройте пути GTK и SQLite, если необходимо.
4. Build -> Rebuild, затем F9. Если есть ошибки, сохраните Build log.
5. Откройте Отделы -> выберите запись -> Открыть.
6. Нажмите Выбрать фото и укажите PNG/JPEG/BMP; нажмите Сохранить и закрыть.
7. Закройте программу и запустите повторно; снова откройте отдел.
8. Проверьте, что картинка отображается; в SQLiteStudio проверьте поле Отделы.Фото.
9. Откройте bin/Debug/main.glade в Glade, проверьте image_otdel и button15/button16.
10. Сделайте настоящие снимки экрана Glade, окна, данных SQLiteStudio и результата Rebuild.
