## 1. Цель
На основе учебного проекта b12 расширить форму редактирования отдела: выбрать изображение, показать его в интерфейсе и сохранить путь к файлу в SQLite.

## 2. Подготовленный исходный код
Файл `main.glade`: элемент `GtkImage image_otdel`, кнопки выбора и очистки.

Файл `otdel.c`: обработчики `on_button15_clicked()`, `on_button16_clicked()`, функции `LoadRecord1()` и `SaveRecord1()`.

Файл `main.c`: миграция `ALTER TABLE Отделы ADD COLUMN Фото TEXT` при отсутствии поля.

## 3. SQL
