ОТЛИЧИЯ ОТ ЗАДАНИЯ 1
- В интерфейсе w_otdel вместо GtkEntry entry_boss используется GtkComboBoxText comboboxtext2.
- LoadRecord1() загружает фамилию руководителя в BossName.
- LoadCombobox1() читает Код сотрудника / Фамилия из таблицы Сотрудники и заполняет список.
- Текущая строка ищется сравнением фамилии с BossName: номера сотрудников могут иметь пропуски.
- SaveRecord1() берет текст gtk_combo_box_text_get_active_text() и записывает фамилию в текстовое поле Руководитель.
- main.h содержит extern GtkComboBoxText *gBossCombo.
- За основу взята проверенная пользователем версия b10 из Tema4_b1_configured.

ЗАПУСК
1. GitHub Desktop: Pull origin.
2. Скопировать папку b10 в C:\Work\Tema4_b2\b10, открыть b10.cbp в Code::Blocks.
3. Проверить Project → Build options → Search directories → Compiler: C:/Prog/CodeBlocks2/SQLite.
4. Build → Rebuild; F9.
5. Отделы → выбрать отдел → Открыть → раскрыть список Руководитель.
6. Выбрать другую фамилию → Сохранить и закрыть.
7. Перезапустить программу; проверить, что выбранная фамилия сохранилась.
8. При возможности подтвердить результат в SQLiteStudio.
