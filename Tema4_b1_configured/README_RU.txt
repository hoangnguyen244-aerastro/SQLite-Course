РЕАЛИЗОВАНО (исходный код в b10/)

  кнопки Сохранить и закрыть / Отмена.

СОХРАНЕНО
База данных преподавателя скопирована без изменения байтов в
b10/bin/Debug/b10.db (исходный файл: Primery/Примеры готовые/b10).
Исходники преподавателя остаются нетронутыми.

КАК ЗАПУСТИТЬ
1. Скопировать каталог b10 целиком в C:\Work\Tema4\b10.
2. Открыть b10.cbp в Code::Blocks 17.12.
3. Проверить в Project → Build options доступность GTK и
   C:/Prog/CodeBlocks2/SQLite/libsqlite3.a.
4. Выполнить Build and Run (F9).
5. Нажать Отделы; выбрать запись; нажать Открыть.
6. Изменить поле Отдел / Руководитель и сохранить.
7. Открыть базу b10.db в SQLiteStudio, подтвердить изменения.

ВАЖНО: графическая сборка и запуск на Windows в текущей сессии
ещё не были проверены. Окончательные изображения и статусы в отчёте
добавляются только после реального запуска.
