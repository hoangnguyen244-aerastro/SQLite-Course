## 2. Подготовка и реализация исходного кода

Создана копия проекта `b10` в папке `Tema4_b1_configured/b10/`. Добавлена форма `w_otdel` с полями `entry_otdel` (наименование отдела) и `entry_boss` (руководитель). В модуле `otdel.c` реализованы загрузка и сохранение текущей записи; `Reload1` обновляет запись в модели GTK после успешного выполнения SQL. Код отдела используется как служебный ключ и не изменяется вручную.

SQL-операция сохранения:

```sql
UPDATE Отделы
SET Отдел = ?, Руководитель = ?
WHERE [Код отдела] = ?;
```

Использование подготовленного запроса защищает от некорректного форматирования пользовательского ввода. Кнопка «Отмена» закрывает форму без сохранения значений в полях.

**Исходный код для приложения к отчёту:**
- `b10/otdel.c`: функции `LoadRecord1()`, `SaveRecord1()`, `ShowOtdel()`.
- `b10/otdeli.c`: функция `Reload1(int otdel)`.
- `b10/main.h`: новые объявления, которые необходимо выделить красным цветом при оформлении PDF/DOCX.
