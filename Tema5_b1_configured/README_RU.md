# Тема 5 — Задание 1. Нормализация БД (Фотосервис)

**Источник:** `template/Tema_5.pdf`, стр. 12–13, вариант «Разработка базы данных для фотосервиса».

Требование преподавателя: выбрать предметную область, спроектировать базу методом нормальных форм, последовательно представить в отчёте **1НФ → 2НФ → 3НФ** (4НФ/5НФ — при необходимости). Для фотосервиса требуются данные **10 клиентов, 5 видов услуг**, причём каждый клиент заказывает не менее двух фотоуслуг.

## Файлы
- `01_schema_3nf.sql` — итоговая модель 3НФ: Клиенты, Услуги, Заказы, Позиции заказа
- `02_seed.sql` — демонстрационные данные: 10 клиентов, 5 услуг, 10 заказов, 20 позиций
- `03_normal_forms_1nf_2nf.sql` — иллюстрация последовательного преобразования 1НФ/2НФ
- `04_checks.sql` — запросы проверки количеств, 2 услуг на клиента и итогового соединения
- `verify_tema5_b1.py` — автоматическая проверка SQL-скриптов во временной базе (без изменения файлов)

## Выполнение в SQLiteStudio 3.1.1
1. Создайте новую БД `Tema5_b1_Fotoservice.db` — **не используйте** b12/b13/b14.
2. Выполните **по порядку** `01_schema_3nf.sql`, `02_seed.sql`, `03_normal_forms_1nf_2nf.sql`, `04_checks.sql`.
3. Отдельно откройте структуру таблиц, сделайте снимки `1НФ`, `2НФ`, итоговой `3НФ`, запроса с числами 10/5/10/20 и пустого результата запроса «меньше 2 услуг».
4. Запускайте каждый скрипт **только один раз** на новой БД: демонстрационные INSERT не являются повторно исполняемыми.
5. Отчёт Word/PDF подготовить после выполнения и реальных снимков экрана.

Для проверки без SQLiteStudio:
```sh
python Tema5_b1_configured/verify_tema5_b1.py
```

## Логика нормализации
- **1НФ:** одна услуга на строку; ФИО разделено на фамилию, имя и отчество; составной ключ (order_id, service_id).
- **2НФ:** отдельные таблицы заказов, услуг, позиций; исключены частичные зависимости от частей составного ключа. В таблице «Заказы_2НФ» специально оставлены данные клиента, чтобы показать транзитивную зависимость.
- **3НФ:** таблица «Клиенты» выделена отдельно, в таблице «Заказы» остаётся только ключ клиента, связь поддерживается внешним ключом; цена услуги на момент заказа хранится в строке заказа.
- Дополнительные 4НФ и 5НФ для выбранной модели не требуются при указанных бизнес-правилах.

**Статус:** SQL подготовлен. Проверку запуска именно на компьютере студента и реальные снимки SQLiteStudio ещё необходимо выполнить.
