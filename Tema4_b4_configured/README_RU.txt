«Пример b13 — работа с датой реализована для таблицы Сотрудники.
Задание: Реализовать работу с датой для таблицы Отделы».
Конкретное название даты «Дата основания» выбрано для учебного проекта; точную формулировку PDF перед сдачей необходимо проверить.

ПРОЕКТ
Папка: Tema4_b4_configured/b13.
Развёрнутая база: bin/Debug/b13.db (копия исходной b10.db).
Миграции схемы: добавляют Фото и [Дата основания] TEXT, если столбцов нет.
Форма: GtkCalendar calendar_otdel; кнопка «Дата не указана».
Значения даты: ISO 8601 YYYY-MM-DD, пустое исходное значение => NULL.
При сохранении используется подготовленный UPDATE с sqlite3_bind_text() / sqlite3_bind_null().
Логика выбора фамилии руководителя и просмотра фотографии сохранена от Заданий 2–3.

ЗАПУСК (Windows)
1. GitHub Desktop -> fetch / checkout ветки review/remaining-coursework-2026-11-23 -> Pull.
2. Копируйте весь b13 в C:\Work\Tema4_b4\b13.
3. Code::Blocks -> Open b13.cbp -> Build > Rebuild -> F9.
4. Отделы -> выбрать запись -> Открыть. Выберите дату основания в календаре.
5. Сохранить и закрыть, затем полностью выйти и перезапустить приложение.
6. Откройте тот же отдел: выбрана сохраненная дата.
7. Откройте b13.db в SQLiteStudio и проверьте колонку [Дата основания].
8. Нажмите «Дата не указана» -> Сохранить -> проверьте NULL.
9. Сделайте реальные скриншоты Glade, даты до и после перезапуска, SQLiteStudio, Build log.
10. Пересмотрите строгое соответствие методическому PDF Tema_4.pdf.
