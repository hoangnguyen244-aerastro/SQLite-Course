# ОТЧЁТ ПО ПРАКТИЧЕСКОЙ РАБОТЕ — ЧЕРНОВИК
**Тема 4, задание 4: Работа с датой в таблице «Отделы»**

## Цель
По образцу учебного проекта b13 реализовать поле даты для отдела на основе GTK+ GtkCalendar и SQLite.

## Реализация
1. В SQLite при необходимости добавляется столбец `[Дата основания] TEXT`.
2. В Glade добавлен `GtkCalendar calendar_otdel` и кнопка очистки даты.
3. `LoadRecord1()` читает год, месяц и день из строки формата ISO 8601.
4. `SaveRecord1()` сохраняет выбранное значение в формате `YYYY-MM-DD`; незаполненная дата сохраняется как `NULL`.
5. Код `main.c` создает столбец без удаления существующих данных.

## SQL
```sql
SELECT Отдел, Руководитель, Фото, [Дата основания]
FROM Отделы WHERE [Код отдела]=?;

UPDATE Отделы
SET Отдел=?, Руководитель=?, Фото=?, [Дата основания]=?
WHERE [Код отдела]=?;
```
