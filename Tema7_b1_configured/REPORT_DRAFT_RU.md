# Отчет — Тема 7, Урок 7.3 (ЧЕРНОВИК)

**Предмет:** Модели управления информационными ресурсами.  
**Пример b16:** простой склад.  
**Точное задание из исходного кода:** добавить обработку всех полей и сделать формы для расходных накладных.

## Цель
Реализовать учет расходных накладных и редактирование полей товара и документа, связанного с остатками склада.

## Ход разработки
- Формы для расходных накладных созданы программно средствами GTK+3.
- Предусмотрены поля номера, даты, поставщика и покупателя.
- Добавлены операции вставки и удаления товарных строк и расчет суммы документа.
- Для движения остатков использованы транзакции SQLite и контроль остатка.
- Для таблицы Товары реализованы поля закупочной и розничной цены и мест хранения.
