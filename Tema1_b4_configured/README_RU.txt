ЗАДАНИЕ ПО PDF (стр. 20):
Открыть проект b3.cbp, заменить загрузку main.glade на main1.glade,
нажать F9 и вывести пустую таблицу с двумя столбцами:
«Столбец 1» и «Столбец 2». Сделать снимки кода и работающей программы.

ПОШАГОВО:
1. Сделайте резервную копию вашего C:\Work\b3, который использовался в задании 3.
2. Скопируйте файлы из этой папки b3 в C:\Work\b3.
3. Убедитесь, что файл main1.glade лежит в C:\Work\b3\bin\Debug\.
4. Откройте b3.cbp в Code::Blocks и запустите F9.
5. Ожидается окно «Задание 3 — Работа с таблицами в Glade»:
   надпись «Пример», пустая таблица с двумя столбцами и кнопка «Закрыть».
6. Нажмите «Закрыть»: окно должно закрыться.
7. Сфотографируйте окно программы вместе с журналом сборки;
   затем исходный файл main.c с строкой загрузки main1.glade.
8. Приложите два настоящих снимка к PDF-отчету.

ТЕХНИЧЕСКОЕ ПОЯСНЕНИЕ:
- GtkBuilder загружает main1.glade из рабочего каталога bin/Debug.
- Окно window1 и кнопка button1 берутся по идентификаторам.
- Сигнал clicked подключается программно с помощью g_signal_connect:
  это надежный способ для среды MinGW под Windows.
- Старые файлы table.c/table.h включены для совместимости с учебным проектом.
- Наличие SQLite в этой практической работе не требуется.
- Запуск на Windows пока не подтвержден: снимки добавляются после проверки.
