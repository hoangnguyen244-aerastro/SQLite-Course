## 1. Цель и задание
В редакторе Glade отключить показ служебного ключевого поля «Код отдела» в форме таблицы «Отделы». Проверить, что приложение b7.exe показывает только пользовательские колонки, а столбец «Код отдела» сохраняется в базе SQLite.

## 2. Ход выполнения
В проекте `b7` используется `main.glade`. Для колонки `treeviewcolumn4` («Код отдела») задано свойство `visible=False`. Колонки «Отдел» и «Руководитель» остаются видимыми. В SQLite структура таблицы определена как:

```sql
CREATE TABLE Отделы (
    [Код отдела] INTEGER PRIMARY KEY,
    Отдел TEXT,
    Руководитель TEXT
);
```

Модель данных и поле ключа в таблице сохранены. Проект `b7.cbp` содержит настройки для компиляции с GTK+ и SQLite.

По скриншотам студента подтверждены следующие результаты:

- **Рисунок 1:** редактор Glade, выбран столбец `treeviewcolumn4` («Код отдела»). Значение `visible=False` непосредственно проверено в исходном файле `main.glade` на GitHub; на самом снимке свойство «Visible» не показано.
