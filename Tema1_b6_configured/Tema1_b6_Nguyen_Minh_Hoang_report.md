## 1. Задание
Открыть проект `b5.cbp` в Code::Blocks. Программно добавить запись в таблицу «Сотрудники». Запустить программу клавишей F9, нажать «Запись в БД» и «Сотрудники». Открыть базу в SQLiteStudio, обновить данные таблицы «Сотрудники». Включить в отчет текст задания и скриншоты измененного кода, формы и SQLiteStudio.

## 2. Ход выполнения
В модуль `table.c` примера b5 добавлен SQL-запрос вставки четвертого сотрудника:

```sql
INSERT INTO Сотрудники VALUES(4,'Смирнов',28000);
```

Программа продолжает использовать исходную таблицу с тремя полями (`N`, `Фамилия`, `Оклад`) и два действия: `SaveDB()` для записи в SQLite, `ShowTable()` для отображения в GtkTreeView. Для сборки добавлены пути к SQLite в `b5.cbp`.
